2026-09-10

## 运行

在 `frontend` 目录执行：

```sh
npm run dev -- --host 127.0.0.1 --port 5180 --strictPort
npm run build
npm test
```

页面地址：`http://127.0.0.1:5180/miniagent/`。

新版入口为 `index.html → app/main.js → app/App.vue`，所有新页面位于 `app/`，没有导入旧 `src/` 下的组件或请求封装。原有前端源码保留。沿用 Vue 3 / Vite 及现有构建依赖，部署基础路径仍为 `/miniagent/`。导航使用 Hash，刷新子页面不依赖额外的服务端路由规则。原测试命令保留为 `npm run test:legacy`；此次没有读取或执行旧页面测试。

复制 `.env.example` 为 `.env.local` 后可以配置 `VITE_API_ROOT`。默认 API 根为同源 `/miniagent/api/v1`，也兼容既有 `VITE_API_BASE` 配置（截止 `/miniagent`）。开发代理默认转发到 `http://127.0.0.1:18080` 的 Docker Nginx；直接启动 Java 后端时将 `MINIAGENT_PROXY_TARGET` 改为 `http://127.0.0.1:8066`。修改环境变量后需要重启 Vite 或重新构建。

## 设计

采用米白、灰绿和深橄榄绿，搭配低饱和杏色、淡紫色标识不同的执行策略。以稳定侧栏、克制的边框、留白和一致的表单为基础，减少密集控制台感。参考了 [Linear](https://linear.app/) 的导航层级、排版节奏和任务信息组织，具体配色、品牌图形、轨道插画、文案和布局独立设计。

所有插画为 CSS/SVG，图标内置，不依赖外部图片。字体使用 DM Sans、Noto Sans SC，并提供系统字体回退，网络不可用时仍可显示。

响应式断点覆盖桌面、平板和手机。手机使用抽屉导航，聊天顶部另设历史会话下拉菜单。弹窗具有焦点限制、Escape 关闭和返回焦点行为；隐藏的手机侧栏使用 inert；Markdown 经 DOMPurify 清理。

## 接口处理

- 普通接口均使用 POST，同时检查 HTTP 状态和 `Result.code`，401 清除认证并打开登录窗口，403 显示权限错误。
- 认证使用服务端平铺 AuthVO，JWT 保存在 sessionStorage。登录/注册及资料返回的 token 会更新本地认证。退出仅清理本地认证。
- JSON 中超过安全整数范围的 Java Long 在解析前转为 BigInt，提交时输出原始数值，防止 flowId 等发生精度损失。
- 新 SSE 解析器保留空白与多行 data，支持 LF、CRLF、CR、网络事件分片以及中文 UTF-8 字节分片。
- 对话 data 按原文追加；任务 message 解析实体；任务 error 保留原文，complete 需要合法完成实体。失败不会被正常 EOF 覆盖。未收到 complete 的任务结束显示状态未知。
- 中断、切换页面或会话会取消当前前端连接，并隔离旧异步回调。不自动重试执行 POST。前端停止接收不等于后台任务被取消。
- 已知历史按 chat 20 条、work 3 条用户消息进行前端限制；每种类型最多 3 个会话。
- 文件使用 `ragTag + fileList` 多 part；个人资料使用 application/json 的 profile Blob 及可选 avatar。
- 个人模型使用 apiId 更新/删除；对话使用 clientId；工作区配置使用 modelId；评论/点赞使用 plazaId；复制使用 templateId。
- 异步发布、复制、删除等文案显示“已提交”。广场交互使用乐观更新和有限刷新，不假定 MQ 已落库，不自动重发操作。
- 密钥输入使用密码字段，列表不显示密钥；没有请求/响应调试日志。

# 前端接口完整清单

[返回对接指南](API.md) · [字段字典](API-SCHEMAS.md)

截至 2026-09-10，5 个业务 Controller 共 **125 个 POST 接口**。下列路径统一追加在 `/miniagent/api/v1` 后。Query 是 URL 查询参数（Spring @RequestParam 也可绑定普通表单），不要改放 JSON。点击 DTO 名查看完整字段与校验。

除登录/注册外均需 Bearer JWT；/admin/* 还需 admin 角色。Result<T> 的 T 是 data。流式/原始文本接口不套 Result。无参数接口无需发送 {}；有 JSON DTO 的查询必须发送对象。示例与错误规则见[对接指南](API.md)。
